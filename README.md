# 노을 LMS · 공개 테스트 페이지

이 저장소에는 노을 노동법률사무소 사이트 시연에 필요한 **정적 화면 파일만** 있습니다.

- 원본 개발 저장소: 비공개 `Noeul-LMS`
- 이 저장소: 공개 테스트 웹사이트 `Noeul-LMS-Preview`
- 구현: 브랜드 포털(`/`), 사무소 홈페이지(`/home/`), LMS 준비 안내(`/lms/`)
- 상담 접수, 로그인, 급여 업무 및 고객 데이터 접근 기능은 제공되지 않습니다.

## GitHub Pages 활성화

GitHub 저장소 `Settings → Pages → Build and deployment`에서 **Deploy from a branch**, `main`, `/ (root)`를 선택하고 Save하면 됩니다.

> 주의: 공개 저장소이므로 고객사 자료, 개인 정보, API 키를 업로드하지 마세요. 이 저장소에는 자동 동기화/배포 워크플로를 설치하지 않았습니다.
